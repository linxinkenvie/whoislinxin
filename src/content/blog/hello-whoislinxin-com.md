一直想给自己留一块真正属于自己的互联网空间。

不是社交媒体主页，不是某个平台里的账号，也不是依赖某个内容平台存在的博客，而是一个只由域名指向的地方。

于是有了：

`whoislinxin.com`

## 为什么叫这个名字？

它首先可以直接读成：

**Who is Linxin?**

但对熟悉 Unix 和互联网的人来说，`whois` 又是一条非常熟悉的命令：

```bash
whois whoislinxin.com
```

WHOIS 可以告诉你一个域名的信息。

但它回答不了真正的问题：

> Who is Linxin?

所以，我想让这个网站自己回答。

```text
$ whois linxin

NAME
    Linxin

STATUS
    Building things.

INTERESTS
    AI / Programming Languages / Linux

DOMAIN
    whoislinxin.com
```

## 这里以后会有什么？

大概什么都会有。

技术笔记、Linux、AI、编程语言、正在做的项目，以及一些只是突然想到、又觉得值得写下来的东西。

我并不打算把这里限制成某一种主题。

它更像是我在互联网上的一块长期空间。

有些文章可能很认真。

有些可能只是几百字的想法。

有些东西也许几年以后回来看会觉得很幼稚。

但这恰好也是建立个人网站的意义之一。

## 技术栈

这个网站现在运行在：

- Astro
- GitHub
- Cloudflare Pages
- Cloudflare DNS

源码通过 Git 管理。

每当我执行：

```bash
git push
```

Cloudflare 会自动重新构建并部署网站。

服务器费用：

**0。**

目前唯一真正需要长期支付的东西，是这个域名。
